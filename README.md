# ESP32 小说阅读器

基于 ESP32-2432S028R（ESP32-D0WD + ILI9341 320x240 + XPT2046 + TF 卡）的轻量 LVGL 小说阅读器，支持在线选书、搜索、TF 归档和本地 TXT 阅读。

开机进入主页，提供“在线阅读”“下载 TXT 到 TF 卡”“本地阅读”三个入口。WiFi、选书、下载和阅读页面均可返回主页。

## 当前状态
- 已在 CH340 真机完成烧录与联网验收；本轮 Windows 重枚举后的端口为 `COM8`。
- 联网后进入选书页，可用全键盘拼音按书名/作者搜索；搜索结果最多常驻 8 条。
- 选书后先下载第一章，写入成功便立即进入阅读器；后续章节沿“下一章”链接渐进发现，无需把几百 KB 的长篇目录载入内存。
- 在线模式只保留阅读位置附近的 5 章：第 1～3 章对应缓存 1～5，第 4 章对应 2～6，第 5 章对应 3～7。
- 在线缓存使用独立的 `cache_NNN.txt` 文件并持久化所属书籍，切换在线书籍不会删除 `spiffs_data` 烧录的本地数字章节。
- 当前章写入后立即进入阅读器，其余四章继续在后台缓存；翻到尚未落盘的章节会显示加载状态并自动打开。
- 装有 TF 卡时，在线阅读已经下载成功的章节会同时永久归档到 TF 卡；SPIFFS 的 5 章滑动缓存被清理后，TF 副本仍然保留并可离线打开。
- 书架页会扫描 TF 卡根目录和 `novels` 文件夹中的 UTF-8 `.txt`，支持长篇 TXT 按需分页、前后翻页、阅读百分比和断点续读，不把整本书载入内存。
- 联网成功后若 WiFi 暂时断开，会按 0.5～8 秒退避自动重连；HTTP 缓存任务会在网络恢复后继续重试。
- 支持目标站当前使用的 gzip 和 chunked 响应；搜索与详情请求会在三个同结构镜像间自动切换，后台失败会自动重试。正文与目录请求固定使用主站地址，只做同主机重试。
- 在线阅读链路按 `main/web_scraper.c` 中的 `http://` 地址直连，不含 TLS 加密与证书校验；HTTPS 与 ESP-IDF certificate bundle 目前只用于“下载 TXT 到 TF 卡”的 TXT80 链路（`main/txt_download_ui.c`）。
- 同一章若被站点拆成多页，会按“请求一页 → 解压解析 → 立即追加临时文件 → 释放 RAM”流水处理；全部分页完成后才原子发布章节。
- 对解压后超过 32KB 的单个网页，压缩数据短暂落入 SPIFFS 后再解压，规避经典 ESP32 的连续堆块上限。
- 正文按字体实际像素高度分页，底部章节/页数栏有独立安全区，不再覆盖最后一行。
- 在线阅读位置保存到正文偏移，重进书籍可恢复到章内页面；两秒合并一次 NVS 写入。向前跨章会打开上一章末页。
- 使用 1-bit 自定义字体 `main/fonts/novel_font_16.c`，覆盖约 9050 个简体/常用繁体字及 UI 字符；字形位于 Flash，不占正文运行内存。
- WiFi 页面采用卡片式布局、状态色和下载进度条，软键盘按需创建以节省内存。
- 左侧触摸：上一页 / 上一章
- 右侧触摸：下一页 / 下一章
- 所有触摸统一经过 100ms 按压确认；不足 0.1 秒的接触不会触发翻页、按钮、键盘或候选字。

## 目录
- `main/` 固件源码
- `main/fonts/novel_font_16.c` 自动生成的中文子集字体
- `main/book_select_ui.c` 选书、拼音输入、搜索结果和首章加载界面
- `main/sd_storage.c` TF 卡挂载、书库扫描、在线章节归档、TXT 分页索引与断点保存
- `main/touch_bitbang.c` XPT2046 GPIO 触摸驱动，为板载 TF 卡释放独立 SPI 控制器
- `spiffs_data/` 烧录到 SPIFFS 分区的出厂数据（当前为空；小说保存在 TF 卡）
- `tools/split_novel.py` 将整本小说拆成章节
- `tools/build_font.js` 根据 `spiffs_data` 里的字符重新生成字体
- `partitions.csv` 分区表（app 3MB，spiffs 960KB）

## 放入本地小说

最方便的方式是不重新烧录：

1. 把 TF 卡格式化为 FAT32。
2. 把 UTF-8 编码的 `.txt` 文件放到卡的根目录或 `novels` 文件夹；支持中文和长文件名。
3. 断电插卡后开机，连接 WiFi 进入“选一本书”页面；文件会显示在“TF 卡书库”中。没有网络时直接点“本地阅读”也会进入这个书架。
4. 阅读进度自动保存。设备还会在卡上创建 `.reader` 分页索引和 `online` 在线章节归档目录，请保留这两个目录。

在线搜索并阅读的书无需另行操作：每个成功下载的章节会保存为 `online/<书籍ID>/<章节号>.txt`，随后可从“TF 卡书库”离线继续阅读。

“下载 TXT 到 TF 卡”连接 TXT80 的整本电子书搜索：输入书名或作者，选择搜索结果后直接下载单个完整 TXT 文件。界面提供两个站点镜像，首选源失败时会自动切换备用源；文件流式保存到 `novels/` 目录，下载完成后可从“本地阅读”打开。该流程只请求搜索页、书籍下载页和一次整本文件，不会逐章抓取。

下载器会自动识别来源文件是 UTF-8 还是 GBK；GBK 内容在写入 TF 卡时分块转换为 UTF-8，因此两种来源文件都能直接由本地阅读器打开，转换过程不加载整本小说。

旧的 SPIFFS 内置方式仍可使用：

1. 把你自己的《斗罗大陆》txt 文件放到项目根目录，例如 `douluo.txt`
2. 拆章节（生成 ASCII 文件名 `001.txt`、`002.txt`...）：
   ```bash
   python tools/split_novel.py douluo.txt spiffs_data
   ```
3. 重新生成覆盖所有正文汉字的字体：
   ```bash
   # 首次需要安装字体转换工具
   npm install
   node tools/build_font.js
   ```
4. 重新编译烧录：
   ```powershell
   idf.py build
   idf.py -p COM12 flash
   ```

## 字体说明
- 使用 Windows 自带的 `C:\Windows\Fonts\simhei.ttf`（黑体）作为源字体。
- 默认生成 GB2312 简体与常用 Big5 繁体字符集，兼顾在线搜索和正文，体积仍适合 4MB Flash。
- 字体脚本会自动收集 `main/*.c` 中的 UI 字符和 `spiffs_data` 正文字符；新增内容后重新运行 `node tools/build_font.js`。

## 注意事项
- ESP32 经典版只有 4MB Flash，在线阅读用 5 章滑动窗口控制占用；窗口外的 `cache_NNN.txt` 会被自动清理，本地 `NNN.txt` 不受影响。
- TF 卡使用板载引脚 SCK=18、MOSI=23、MISO=19、CS=5，以 10MHz SPI 模式挂载。固件不会自动格式化无法识别的卡，以免清除卡内数据。
- TF 本地 TXT 当前要求 UTF-8 编码；GBK/ANSI 文件需先在电脑上另存为 UTF-8。
- 在线章节索引只保存 32-bit 章节 ID（每章 4 字节），正文仍严格限制为 5 个正式章节文件，因此可持续读到末章；下载中的临时文件不计入缓存窗口。
- 章节文件第一行会作为标题显示。
- 阅读页右上角可调节 10%–100% 背光亮度；松开滑杆后保存，重启自动恢复。
- 阅读页可随时进入书架/搜索页；最近阅读的 6 本书会保存书名与章节进度，重新打开时从记录位置恢复。
- 搜索输入改为全键盘拼音，候选栏扩展为 8 项；输入时暂时收起书架，完成后恢复列表空间。
- 中文字体缺少的键盘控制图标会回退到 LVGL Montserrat 字体，发送、删除、关闭和方向键均可正常显示。
- 后续可扩展：更多书源、自定义阅读字号。
